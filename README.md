Dieses kleine Tool ist dazu gedacht Eve-Online Clients im fensterlosen Modus auf dem Desktop zu verschieben.

Die zu verschiebenden Fenster einfach in der Auswahlliste auswählen und 'verschieben' klicken.

Die Vorschau kann genutzt werden um sich eine Übersicht über die Aufteilung auf dem Desktop zu verschaffen.

- minimierte Fenster werden ausgeblendet
- kleine Fenster wie z.B. von Eve-O-Preview werden ausgegraut aufgelistet, können aber auch verschoben werden.

Das Python-File wurde mit [Nuitka](https://nuitka.net/) in ein Exe-File kompiliert. Falls die übliche Virus Meldung kommt bitte ignorieren weil nix signiert etc.

Falls das Programm nicht startet bitte Visual C Runtime libraries von MS installieren.
